# Radiuma
Access Link: https://radiuma-doucumentation.readthedocs.io/en/latest/
**Radiuma** is a comprehensive toolkit for advanced medical image analysis and machine learning.  
It integrates a broad set of processing tools and algorithms into standardized, end-to-end workflows, enabling reproducible research and seamless integration across diverse components within a unified framework.

## Key Features

### 🖥️ Advanced Image Viewer
- Interactive **3D viewer** for images and segmentations.

### 🧬 Advanced Image Analysis
- Multiple options for **image registration**, **fusion**, and related operations.

### 🔬 Standardized Radiomics Analysis
- Fully compliant with **IBSI 1.0** standards.

### 🎛️ Advanced Image Filtering
- Standardized against **IBSI 2.0**.
- Includes a wide range of configurable filters.

### 🤖 Comprehensive Machine Learning Tools
- Built-in tools for **classification**, **regression**, and **clustering**.

### 🤝 Collaborative Research Support
- Ensures consistency and comparability across different studies and institutions.

### 🧑‍⚕️ User-Friendly Interface
Designed to support a broad range of users, including:
- Radiation oncologists  
- Radiologists  
- Medical physicists  
- Data scientists  

### 🔗 End-to-End Workflows
- Seamlessly connects various imaging and analysis tools.

### 🗂️ Multi-Tab Workflow Support
- Run multiple independent workflows in parallel.

### 🎚️ Workflow Control System
- Granular execution control:
  - **Node-level** stopping  
  - **Global** workflow stopping
